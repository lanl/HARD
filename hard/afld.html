Overview of Variables

Three user-input variables have been implemented as part of AFLD:

  1. limiter_id: Integer varying from 0 to 4. Corresponds to the limiter relation to be used. The default is 1.

  2. closure_id: Integer varying from 0 to 4. Corresponds to the closure relation to be used. The default is 3.

Besides this, the Eddington Factor field was implemented to store the values returned by invoking the relation specified in closure_id.

Limiter Relations

Here \(R\) is the energy gradient ratio given as input to the function, along with the limiter_id. \(\lambda\) is the limited flux value returned as output by the function.

\[R = \frac{|\nabla E_r|}{\kappa \rho E_r}\]

limiter_id = 0

Fixed value \(\frac{1}{3}\)

\[\lambda = \frac{1}{3}\]

limiter_id = 1

Approximate Levermore–Pomraning limiter:

\[\lambda = \frac{2 + R}{6 + 3R + R^2}\]

limiter_id = 2

Bruenn limiter:

\[\lambda = \frac{1}{3 + R}\]

limiter_id = 3

Larsen’s Square Root limiter:

\[\lambda = \frac{1}{\sqrt{9 + R^2}}\]

limiter_id = 4

Minerbo limiter:

\[\begin{split}\lambda = \begin{cases} \dfrac{2}{3 + \sqrt{9 + 12R^2}}, & R < 1.5 \\ \dfrac{1}{1 + R + \sqrt{1 + 2R}}, & \text{otherwise} \end{cases}\end{split}\]

Closure Relations

Here \(\lambda\) is the flux value given as input to the function, along with the limiter_id and closure_id. \(E\) is the Eddington Factor returned as output.

closure_id = 0

\[E = \lambda\]

closure_id = 1

\[E = \frac{1}{3}\]

closure_id = 2

\[E = 1 - 2\lambda\]

closure_id = 3

Analogous to Levermore–Pomraning type, i.e. \(E = \lambda + (\lambda R)^2\)

  • limiter_id = 0

\[E = \frac{1}{3}\]

  • limiter_id = 1

\[t = \frac{1}{2}\max(0, 1-3\lambda) + \sqrt{\max(0, (1-3\lambda)(1+5\lambda))}\]
\[E = \lambda + t^2\]

  • limiter_id = 2

\[E = 1 - 5\lambda + 9\lambda^2\]

  • limiter_id = 3

\[E = 1 + \lambda - 9\lambda^2\]

  • limiter_id = 4

\[\begin{split}E = \begin{cases} 1 + 3\lambda - 2\sqrt{2\lambda}, & E < \frac{2}{9} \\ \dfrac{1}{3}, & \text{otherwise} \end{cases}\end{split}\]

closure_id = 4

Modification of Levermore–Pomraning type: \(E = \frac{1}{3} + \frac{2}{3}(\lambda R)^2\)

  • limiter_id = 0

\[E = \frac{1}{3}\]

  • limiter_id = 1

\[t = \max(0, 1-3\lambda) + \sqrt{\max(0, (1-3\lambda)(1+5\lambda))}\]
\[E = \frac{1}{3} + \frac{t^2}{6}\]

  • limiter_id = 2

\[E = \frac{1}{3} + \frac{2}{3}(1 - 6\lambda + 9\lambda^2)\]

  • limiter_id = 3

\[E = \frac{1}{3} + \frac{2}{3}(1 - 9\lambda^2)\]

  • limiter_id = 4

\[\begin{split}E = \begin{cases} \dfrac{1}{3} + \dfrac{2}{3}\left(1 + 2\lambda - 2\sqrt{2\lambda}\right), & E < \frac{2}{9} \\ \dfrac{5}{9} - \dfrac{2}{3}\lambda, & \text{otherwise} \end{cases}\end{split}\]
